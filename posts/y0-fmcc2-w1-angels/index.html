Y0/FMCC2/W1 – Angels

February 16, 2026 · UAL, Year 0, FMCC2

This week we are looking at colour space. The most commonly used and understood colour representation for digital images is RGB. This uses three values, usually 8 bits per value to represent the brightness of red, green and blue components of an image.

RGB can be easily represented as hexadecimal with two characters corresponding to each component. You can learn to intuit the hex code of any colour by looking at it. the first digit of each component from 0-F is rough, then finer adjustments can be made with the second. You can instinctually estimate the amount of red, green, and blue in a colour to impress your friends.

This is however, very difficult to do so there are more human friendly colour formats. HSV is one of them. HSV is made of three components, just like RGB.

Hue, ranging from 0 - 360, describes the angle on the colour wheel.
Saturation, ranging from 0 -100, describes how vivid the colour is.
Value, ranging from 0 - 100, describes how bright the colour is.

HSV makes it much easier to compute complementary and harmonious colours. It also allows us to easily acquire tints and shades of a colour.

I've created a version of my p5js clock from [[y0-fmcc-w6-tempus-fugit]] that randomly picks a colour in the HSB space and builds a complementary palette on top.

function generateColors(base_hue,base_sat,base_brt) {
  let bg = color(base_hue,base_sat,base_brt);
  
  //pupils: split complementary
  let splitComp = 10;
  
  let pupilDormant = color(abs((base_hue + 180 + splitComp) % 360),base_sat*0.3,base_brt);
  let pupilActive = color(abs((base_hue + 180 - splitComp) % 360),100,50); 
  
  let txt = pupilActive;
  let sclera = color(abs((base_hue + 30)),base_sat,base_brt+25); //analogous + brightened
  
  return new style(bg,txt,pupilDormant,pupilActive,sclera,`${round(base_hue)} ${round(base_sat)} ${round(base_brt)}`);
}

I used a bit of a hack to get it working. Not the most elegant solution.

styles[styleIndex] = generateColors(random(360),random(100),random(100));

I always make sure to use the modulo function to wrap the hue around. It does still take a bit of discretion to find what looks good. Personally I prefer my hand-picked palettes but there are some surprisingly pleasant combinations.
