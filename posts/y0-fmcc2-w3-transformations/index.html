Y0/FMCC2/W3 - Transformations

March 2, 2026 · UAL, Year 0, FMCC2

This week I've been learning Three.js. The sketch is inspired by Vera Molnár's Interruptions (1969), one of her earliest computer-generated plotter drawings. In it, she fills a grid with line segments of equal length and applies random rotation to each one, creating a dense, chaotic field from an otherwise uniform structure. I wanted to explore the same idea but extended into three dimensions.

Setup

Every Three.js sketch needs three things: a scene, a camera, and a renderer.

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera( 30, window.innerWidth / window.innerHeight, 0.1, 1000 );

const renderer = new THREE.WebGLRenderer();
renderer.setSize( window.innerWidth, window.innerHeight );
document.body.appendChild( renderer.domElement );

A lot of this code was copy-pasted from the Three.js manual, specifically https://threejs.org/manual/#en/creating-a-scene. I have tried to understand everything going on.

The Grid

I create a 16×16×16 volumetric grid of line segments, each randomly oriented.

for(let x = 0; x < volGridWidth; x++){
  for(let y = 0; y < volGridHeight; y++){
    for(let z = 0; z < volGridDepth; z++){
      let points = [];
      let angle = Math.random(6.28);
      //set local geometry to line of length voxelSize
      points.push( new THREE.Vector3( voxelSize*-0.5, 0, 0 ) );
      points.push( new THREE.Vector3( voxelSize*0.5, 0, 0 ) );
      //create line object
      let geometry = new THREE.BufferGeometry().setFromPoints( points );
      let material = new THREE.LineBasicMaterial( { color: 0xffffff } );
      let line = new THREE.Line( geometry, material );
      //apply random rotations in three axis
      line.rotateX(Math.random()*6.28); //6.28 approx 2*PI
      line.rotateY(Math.random()*6.28);
      line.rotateZ(Math.random()*6.28);
      line.position.set( x * voxelSize, y * voxelSize, z * voxelSize ); //set position to grid
      
      volGrid.push(line); 
      scene.add( line );
    }
  }
}

Each line starts as a horizontal segment and is rotated randomly on all three axes. This similar to Molnár's Interruptions logic, but in 3D.

Animation

Three.js uses setAnimationLoop instead of p5's draw().

function animate( time ) {
  volGrid.forEach( line => {
    line.rotateY(0.02);
    line.material.color.set(`hsl(${(line.position.y * 8) + (time / 10)}, 100%, 50%)`) //pulsing hue effect
  });

  renderer.render( scene, camera );
}
renderer.setAnimationLoop( animate );

Each frame every line rotates on the Y axis. The colour is an HSL value where the hue is driven by the line's Y position plus a time offset resulting in a rainbow wave that travels down the cube, adding motion to Molnár's work.
