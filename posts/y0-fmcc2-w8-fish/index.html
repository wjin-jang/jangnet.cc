Y0/FMCC2/W8 - Fish

May 18, 2026 · UAL, Year 0, FMCC2

I created a fish tank simulation in Three.js using the principles of boids. The fish have alignment, separation, cohesion and avoidance behaviours.

Part One

Creating A Class

I made a fish class to act as a boid. It has position, velocity and acceleration all using Three.js' Vector3.

export class Fish {
	constructor(pos) {
		this.pos = pos;
		this.vel = new THREE.Vector3(
			(Math.random() - 0.5) * 2,
			(Math.random() - 0.5) * 2,
			(Math.random() - 0.5) * 2
		);
		this.acc = new THREE.Vector3(0, 0, 0);
	}
}

I gave the fish a flat plane geometry and basic textured material.

this.geometry = new THREE.PlaneGeometry(9, 4);
this.material = new THREE.MeshBasicMaterial({
	map: texture,
	transparent: true,
	alphaTest: 0.1,
	side: THREE.DoubleSide
});

this.mesh = new THREE.Mesh(this.geometry, this.material);
this.mesh.position.copy(this.pos);

Part Two

Calculating Forces

I created methods to calculate the alignment, cohesion, and separation forces. All three require iterating through all other fishes, which does pose some performance concerns. At a smaller number of fishes it should perform fine. 

alignment(fishes) {
	const neighbours = this._neighbours(fishes);
	if (!neighbours.length) return new THREE.Vector3();
	
	const steering = new THREE.Vector3();
	neighbours.forEach(f => steering.add(f.vel));
	steering.divideScalar(neighbours.length);
	steering.setLength(MAX_SPEED);
	steering.sub(this.vel);
	steering.clampLength(0, MAX_FORCE);
	return steering;
}

  

cohesion(fishes) {
	const neighbours = this._neighbours(fishes);
	if (!neighbours.length) return new THREE.Vector3();
	
	const steering = new THREE.Vector3();
	neighbours.forEach(f => steering.add(f.pos));
	steering.divideScalar(neighbours.length);
	steering.sub(this.pos);
	steering.setLength(MAX_SPEED);
	steering.sub(this.vel);
	steering.clampLength(0, MAX_FORCE);
	return steering;
}

  

separation(fishes) {
	const neighbours = this._neighbours(fishes);
	if (!neighbours.length) return new THREE.Vector3();
	
	const steering = new THREE.Vector3();
	neighbours.forEach(f => {
			const d = this.pos.distanceTo(f.pos);
			const diff = new THREE.Vector3().subVectors(this.pos, f.pos);
			diff.divideScalar(d * d);
			steering.add(diff);
	});
	steering.divideScalar(neighbours.length);
	steering.setLength(MAX_SPEED);
	steering.sub(this.vel);
	steering.clampLength(0, MAX_FORCE);
	return steering;
}

Part Three

Applying Forces

Finally, the update method calls every function and adds their result to the acceleration. The mesh position is updated.

update(fishes, tankSize) {
	const alignment = this.alignment(fishes).multiplyScalar(1.5);
	const cohesion = this.cohesion(fishes).multiplyScalar(1.0);
	const separation = this.separation(fishes).multiplyScalar(1.5);
	
	this.acc
		.add(alignment)
		.add(cohesion)
		.add(separation);
	
	this.vel.add(this.acc).clampLength(0, MAX_SPEED);
	this.pos.add(this.vel);
	this.acc.set(0, 0, 0);
	
	this.mesh.position.copy(this.pos);
}

Part Four

Multiple Flocks

I gave each fish a 'flock ID' which determines its texture and behaviour. 

_neighbours(fishes) {
	// Same flock only
	return fishes.filter(f => f !== this
		&& f.flockId === this.flockId
		&& this.pos.distanceTo(f.pos) < PERCEPTION_RADIUS);
}

_outsiders(fishes) {
	// Different flocks within a larger radius	
	return fishes.filter(f => f.flockId !== this.flockId
		&& this.pos.distanceTo(f.pos) < PERCEPTION_RADIUS * 1.5);
}

The FIsh object gets a method to determine its neighbours and outsiders given all fishes. Now, it only iterates through its neighbours and an additional function is added to make it avoid outsiders.

avoidOtherFlocks(fishes) {
	const outsiders = this._outsiders(fishes);
	if (!outsiders.length) return new THREE.Vector3();
	
	const steering = new THREE.Vector3();
	outsiders.forEach(f => {
		const d = this.pos.distanceTo(f.pos);
		const diff = new THREE.Vector3().subVectors(this.pos, f.pos);
		diff.divideScalar(d * d);
		steering.add(diff);
	});
	steering.divideScalar(outsiders.length);
	steering.setLength(MAX_SPEED);
	steering.sub(this.vel);
	steering.clampLength(0, MAX_FORCE * 2);  
	return steering;
}

avoidWalls(tankSize) {
	const margin = 50;
	const force = MAX_FORCE * 3;
	const steering = new THREE.Vector3();
	
	if (this.pos.x < margin) steering.x += force * (1 - this.pos.x / margin);
	if (this.pos.x > tankSize.x - margin) steering.x -= force * (1 - (tankSize.x - this.pos.x) / margin);
	if (this.pos.y < margin) steering.y += force * (1 - this.pos.y / margin);
	if (this.pos.y > tankSize.y - margin) steering.y -= force * (1 - (tankSize.y - this.pos.y) / margin);
	if (this.pos.z < margin) steering.z += force * (1 - this.pos.z / margin);
	if (this.pos.z > tankSize.z - margin) steering.z -= force * (1 - (tankSize.z - this.pos.z) / margin);

	return steering;
}

I also added a function to avoid walls. This force gets stronger the closer the fish gets to the wall.

Part Five

Background

I created a function to make a gradient texture to use as the background. This function takes structs of position and colour and adds them as stops, creating a smooth gradient between colours.

function createGradientBackground(stops) {
	const canvas = document.createElement('canvas');
	canvas.width = 1;
	canvas.height = 256;
	
	const ctx = canvas.getContext('2d');
	const gradient = ctx.createLinearGradient(0, 0, 0, 256);
	
	stops.forEach(stop => {
		gradient.addColorStop(stop.position, stop.color);
	});
	
	ctx.fillStyle = gradient;
	ctx.fillRect(0, 0, 1, 256);
	
	const texture = new THREE.CanvasTexture(canvas);
	texture.colorSpace = THREE.SRGBColorSpace;
	texture.minFilter = THREE.LinearFilter;
	
	return texture;
}

]);
