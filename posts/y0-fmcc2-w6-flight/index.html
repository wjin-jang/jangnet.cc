Y0/FMCC2/W6 - Flight

April 20, 2026 · UAL, Year 0, FMCC2

p5's noise function can take two coordinates and return a float value between 0 and 1. This value is interesting because it represents a smooth gradient. This lends itself well to terrain generation.

function draw() {
  background(220);
  
  for(let gx = 0; gx < gridSizeX; gx++){
    for(let gy = 0; gy < gridSizeY; gy++){
      let noiseScale = 0.1;
      let img = img_water;
      
      if(noise(
        (gx + player.mapX*0.1)*noiseScale,
        (gy + player.mapY*0.1)*noiseScale) > 0.6)
      { img = img_beach }
      if(noise(
        (gx + player.mapX*0.1)*noiseScale,
        (gy + player.mapY*0.1)*noiseScale) > 0.65)
      { img = img_tree }
      
      image(img,gx*gridelSize, gy*gridelSize);
    }
  }
  player.step();
  player.show();
}

I iterate over a grid and determine whether to place water, sand or land using the noise function's output as a heightmap. The player's position is used to offset the noise function, to make it appear as if we are moving through the world.
