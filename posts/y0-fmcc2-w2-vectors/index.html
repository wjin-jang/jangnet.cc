Y0/FMCC2/W2 – Vectors

February 28, 2026 · UAL, Year 0, FMCC2

This week we are looking at Vectors in Euclidean space. I built a sketch where coloured balls bounce around the canvas, colliding with each other and the walls.

Setup

Each ball has a position, velocity, and acceleration. Forces are accumulated into the acceleration each frame, applied to velocity, then cleared.

update() {
  this.vel.add(this.acc);
  this.pos.add(this.vel);
  this.acc.mult(0);
  ...
}

applyForce(force){
  this.acc.add(force);
}

This is a standard Euler integration setup. Gravity is applied every frame as a constant downward force, controllable via a slider ranging from -1 to 1. Negative gravity floats the balls upward.

Wall Collisions

When a ball hits a wall, its velocity on that axis is flipped and scaled by a collision strength factor.

collideWalls(){
  if(this.pos.y > height - this.size*0.5){
    this.vel.y *= -COLLISION_STRENGTH.value();
    this.pos.y = height - this.size*0.5;
  }
  ...
}

The position is also corrected to prevent the ball from clipping through. A collision strength of 1 is perfectly elastic; lower values lose energy on each bounce.

Ball Collisions

Ball-to-ball collision uses an equal-mass elastic collision along the collision normal.

collide(other) {
  let normal = p5.Vector.sub(this.pos, other.pos);
  let distance = normal.mag();
  let overlap = this.size - distance;
  
  normal.normalize();
  
  let moveAmount = normal.copy().mult(overlap / 2);
  this.pos.add(moveAmount);
  other.pos.sub(moveAmount);

  let v1n = this.vel.dot(normal);
  let v2n = other.vel.dot(normal);

  this.vel.add(normal.copy().mult((v2n - v1n) * COLLISION_STRENGTH.value()));
  other.vel.add(normal.copy().mult((v1n - v2n) * COLLISION_STRENGTH.value()));
}

First, the overlap is resolved by pushing both balls apart equally. Then the velocity components along the normal are projected using dot products and exchanged. This gives convincing billiard-ball style collisions.

The collision detection is O(n²) every ball checks every other ball. This is fine for a few hundred balls but would need a spatial hash or quadtree to scale further.

Mouse Repulsion

Holding the mouse button pushes nearby balls away. The force falls off linearly within an 80px radius.

applyMouseRepulsion() {
  let fromMouse = p5.Vector.sub(this.pos, createVector(mouseX, mouseY));
  let distance = fromMouse.mag();
  let radius = 80;
  if (distance < radius) {
    fromMouse.normalize();
    fromMouse.mult((1 - distance / radius) * PUSH_STRENGTH.value());
    this.applyForce(fromMouse);
  }
}

Push strength is controlled by a slider. Clicking also spawns 8 new balls near the cursor each time.

Colour

The balls are coloured from a random album cover loaded from my music server. The image is resized to a low-res grid and each pixel's colour is assigned to a ball. After processing, the image is crushed to 1×1 and its luminance measured to set the background colour, so there's always decent contrast regardless of what loads.

let luminance = (evaluateImg[0]*0.299 + evaluateImg[1]*0.587 + evaluateImg[2]*0.114) / 256;
bgColor = luminance > 0.5 ? 15 : 220;

As a fun bonus, holding any key activates a homing force that pulls each ball back toward its pixel's original position so the whole thing can reassemble into the album cover.
