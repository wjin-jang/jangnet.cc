Y0/ICoP/W2 - Cybernetics

February 24, 2026 · UAL, art, coding, ICoP

An .svg file is really simple, actually. Open one up in Notepad and it's like an html file. It could use some formatting but I didn't expect it to be so human readable.

<rect fill="rgb(255,255,255)" stroke="none" x="0" y="0" width="1188" height="840" transform="matrix(1 0 0 1 0 0)" fill-opacity="1"/>

Anyway, we are drawing with robots today. Last week I prepared a sketch in p5js looking to imitate the style of Vera Molnar.

I drew a mockup pattern, based on the beauty of a sine wave with its amplitude multiplied randomly across each shape. Beauty and chaos.

A quick mockup in p5.js shows my intended design. Then it came time to send the path to the AxiDraw machine.
I knew looking at my design that it would take a long time, so just for testing, I simplified it. Instead of drawing a shape, it simply created a line between points.

function drawWaves() {
  background(255);
  let rows = 6
  
  rows++;
  
  for(let r = 1; r < rows; r++){
    beginShape()
    for(let x = 0; x < width; x += 8){
      let amp = random(10)*4;
      let y = (height/rows) * r + sin(0.05*x)*amp;
      
      //drawShape(round(random(shapes.length-1)),x,y,4);
      
      vertex(x,y);
    }
    endShape();
  }
}

To interface with the robot, we used Inkscape and an AxiDraw plugin. It was difficult to line up the drawing arm properly. I didn't understand how the robot decided where to draw from. It was quite a revelation when I realised that the robot doesn't care about its absolute position. It simply draws from wherever it happens to be.

My code is configurable, so that the amplitude, frequency and variance can be adjusted to create various images. I actually preferred the new design. By simplifying I could actually showcase the most interesting part of this algorithm artistically, the ordered chaos emerging from the mixing of a sine wave and random variation.
